# youtube_clone

Projeto Flutter inspirado na interface do YouTube.

O app foi feito para apresentar uma versão simples do YouTube, com tela inicial, navegação por abas, cards de vídeos e shorts, além de capas carregadas a partir dos vídeos reais.

## Sobre o trabalho

Este trabalho foi desenvolvido em grupo para praticar organização de telas, componentes reutilizáveis e consumo de imagens pela internet no Flutter.

## O que o app mostra

- Layout inspirado no YouTube
- Lista de vídeos e shorts
- Capas dos vídeos exibidas no app
- Estrutura separada em telas, widgets e tema

## Estrutura principal

- `lib/main.dart`
- `lib/app.dart`
- `lib/screens/`
- `lib/widgets/`
- `lib/theme/`

## Execução

Para rodar o projeto:

```bash
flutter pub get
flutter run
```
